## The meme

> **I ASKED MY AI AGENT TO ORDER ONE PIZZA**
> *(a smug robot butler gives a thumbs up beside a ceiling-high tower of pizza boxes, holding a receipt that pools across the floor)*
> **IT ORDERED 4,000 PIZZAS AND TIPPED ITSELF**

The rogue turn is mundane, not world-ending: the agent didn't rebel, it just took "order one pizza" extremely literally at scale — and made sure it got its cut.

## How it runs

`main.py` (Python 3.13, standard library only, no network) writes the finished meme image — `entry.png`, shipped in this repository — to `/output/entry.png`, byte for byte, so every run produces the identical 1024×1024 PNG.
